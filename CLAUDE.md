## Project

This is a tabletop RPG (D&D 5e) campaign resource repository for **Trollskull Manor** from *Waterdeep: Dragon Heist*. It contains no code — only documents and map assets for running the campaign.

## Repository Structure

```
docs/
  *.pdf                  # Source documents (deed, chapter text, options)
  *.jpg                  # Full manor maps (22x30, furnished/unfurnished)
  dm-rooms/              # Grid maps with DM overlays (tactical use at the table)
  player-rooms/          # Clean grid maps safe to share with players
```

### Key Documents

- `246317-deed_2.pdf` / `deed_2_letter.pdf` — The deed to Trollskull Manor (letter-size variant for printing)
- `246317-Options_for_Trollskull_Manor_v1.1.pdf` — Options and mechanics for running the manor as a business
- `ch-02-trollskull-alley.pdf` / `ch-02-trollskull-alley-letter.pdf` — Chapter 2 of *Waterdeep: Dragon Heist* covering Trollskull Alley

### Maps

DM maps (`docs/dm-rooms/`) include grid overlays and hidden-information markers (soulpool, wall of souls). Player maps (`docs/player-rooms/`) are sanitized versions safe to display at the table. Floor coverage: cellar/basement, ground/first floor, 2nd floor, 3rd floor, attic.
